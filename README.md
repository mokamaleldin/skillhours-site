# SkillHours Site

Public website for **SkillHours**, an offline-first skill-hours tracking app.

The site provides the public pages required for App Store distribution:

- Landing page
- Support page
- Privacy Policy

## Public URLs

Once GitHub Pages is enabled for the `main` branch:

- Website: https://mokamaleldin.github.io/skillhours-site/
- Support: https://mokamaleldin.github.io/skillhours-site/support/
- Privacy Policy: https://mokamaleldin.github.io/skillhours-site/privacy/

## App Store Connect

Use:

**Support URL**
```
https://mokamaleldin.github.io/skillhours-site/support/
```

**Privacy Policy URL**
```
https://mokamaleldin.github.io/skillhours-site/privacy/
```

## Tech

Plain HTML + CSS. No build process, JavaScript framework, package manager, analytics, cookies, or external dependencies are required.

## Publishing with GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
